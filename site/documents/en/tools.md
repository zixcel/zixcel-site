## zix domain

ValueDomain reads, public DNS and delegation inspection, plus reviewed DNS plans and writes. Establish the authoritative provider first. Official version 0.4.1.

::document-link{href="/tools/domain" title="Install, features and usage"}
::

## zix cloudflare

Account and DNS reads with explicitly scoped configuration observations. DNS audit does not enumerate Workers or Pages. Official version 0.3.1.

::document-link{href="/tools/cloudflare" title="Install, features and usage"}
::

## zix microsoft

Microsoft Graph and Exchange Online administration, with operation-specific credential audiences, scopes, consent, RBAC and target requirements. Official version 0.5.1.

::document-link{href="/tools/microsoft" title="Install, features and usage"}
::

## zix github

Read the expected authenticated user and selected repository metadata. This native extension does not expose issue or pull request writes. Official version 0.2.0.

::document-link{href="/tools/github" title="Install, features and usage"}
::

## zix docker

Docker Hub repository/tag reads, bounded public snapshots and reviewed retirement plans. Uncertain deletes require readback. Official version 0.3.0.

::document-link{href="/tools/docker" title="Install, features and usage"}
::

## zix azure

Read a selected Azure subscription or subscriptions visible to the supplied credential. Official version 0.2.0.

::document-link{href="/tools/azure" title="Install, features and usage"}
::

## zix apple

Read selected App Store Connect app metadata and the app list visible to an API key. Official version 0.2.0.

::document-link{href="/tools/apple" title="Install, features and usage"}
::

## zix google

Read projects, IAM key metadata, scoped resource inventory and existing billing exports, without enabling APIs or creating SQL jobs. Official version 0.7.0.

::document-link{href="/tools/google" title="Install, features and usage"}
::

## zix wordpress

Use origin-bound OS custody for post/page/media reads and explicitly reviewed WordPress changes. Official version 0.4.1.

::document-link{href="/tools/wordpress" title="Install, features and usage"}
::
