# 紹介サイトとフィードバックの運用

このownerが紹介内容と公開snapshotを保守します。共通のNuxt rendererを使い、個人の経歴・顧客・提供実績や実運用機能は確認済みの事実だけを掲載します。新しい一覧/個別紹介のUIはlocalized-site 0.2.2候補で検証し、正式module公開後に公式registryの依存とlockへ切り替えます。検証用のlocal archive参照は製品manifestへ残しません。

公開準備ではcontent/audience、LICENSE/NOTICE、origin/worker/source bindingを確認し、previewと実際の公開URL・内容の確認を分けます。利用数は同じ期間の公式観測を使い、未取得・期限切れ・0件を区別します。statsはunique usersや稼働保証ではありません。

フィードバックにはページURL、owner、source/package版、利用目的、期待する挙動、公開可能な再現手順と分類（内容/API/Schema/配置/不具合）を添えます。該当ownerのIssue等へ集約し、秘密鍵・token・実顧客dataは要求しません。最終物理名だけを理由に制作を止めず、ページとconsumerから責務・配置を見直します。
