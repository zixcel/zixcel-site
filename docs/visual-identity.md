# Visual identity

The header, overview illustration, feature icons and project cards share a visual hierarchy while retaining this site's own colors and approved brand artwork.

- Brand marks retain their proportions; raster artwork is copied without alteration.
- Local SVG line icons identify capabilities. Visible text supplies each name and meaning; repeated decorative images use empty alt text.
- Header marks use 36–48 px, feature icons 30–36 px and product badges 58–72 px. The overview uses a larger mark and connected capability symbols.
- Images and CSS are committed to this repository. No image CDN, remote icon font or management repository is required to build or serve the site.
- Update branding/visuals.css, local brand assets and the relevant components together. Keep narrow screens, focus styles and reduced motion usable.
- Advance the owned site release version and use the repository's tag workflow when publishing. Registry/package publication is not required for these static visual changes.

Brand-specific sources remain documented with the assets and in site-branding.md. Themes and product availability claims are maintained independently from these decorative visuals.
